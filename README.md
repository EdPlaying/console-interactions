<p align=center>During the development process if you don't have the front-end ready yet then is when Console Interactions comes, everyone needs testing their code during the development. </p>

<h2>Features</h2>

<h3>Basics 🫠</h3>
  <p>Take inputs from the console.</p>
<ul>
  <p>Class <b>ScannerUtils</b></p>
  <li>captureInt(message): Int</li>
  <li>captureDouble(message): Double</li>
  <li>captureText(message): Strings</li>
</ul>

<h3>Medium 😎</h3>
  <p>Create selection menus like this one:</p>
  <div><img width="194" height="212" alt="image" src="https://github.com/user-attachments/assets/98be19b1-3b00-4b6c-a223-3baaefa0f468" /></div>

  <div><img width="569" height="97" alt="image" src="https://github.com/user-attachments/assets/ebea4f73-c5ae-46cd-86c2-b7715487e779" /></div>

    <li>You can leave there as many characters as you prefer, CI will format it by itself.</li>
    <li>The numeration will be automated.</li> 
    <li>All the messages are customizable!</li>
